# Excel 转高清图片工具

这是一个免费的工具，可以将 Excel 文件转换为高清 PNG 图片，特别优化了 iOS 端的使用体验。

## 功能特点

- 📁 支持上传 Excel 文件（.xlsx, .xls）
- 📊 实时预览 Excel 内容
- 🖼️ 生成高清 PNG 图片（3倍缩放）
- 💾 一键下载图片
- 📱 响应式设计，支持手机访问
- 📲 iOS 端文件分享支持
- 🎯 JSBox 脚本支持（iOS 端一键转换）
- 🌐 PWA 支持（可添加到主屏幕）

## 使用方法

### 方法 1：iOS 端通过文件分享一键转换

#### 方式 A：PWA 应用（推荐）

1. 在 iOS Safari 浏览器中打开部署好的网站
2. 点击分享按钮（底部中间的正方形带箭头图标）
3. 选择「添加到主屏幕」
4. 在主屏幕上打开「Excel转图片」应用
5. 从其他应用（如文件、邮件等）分享 Excel 文件到该应用
6. 自动转换并生成高清图片
7. 点击「下载 PNG 图片」保存

#### 方式 B：JSBox 脚本

1. 在 App Store 下载并安装 **JSBox** 应用
2. 复制 `excelToImage.jsbox` 脚本内容
3. 在 JSBox 中创建新脚本，粘贴内容并保存
4. 从其他应用分享 Excel 文件到 JSBox 脚本
5. 脚本会自动转换并生成图片
6. 选择「保存到相册」或「分享图片」

### 方法 2：本地打开

1. 直接双击 `index.html` 文件在浏览器中打开
2. 点击「选择文件」上传 Excel 文件
3. 点击「开始转换」按钮
4. 预览转换结果
5. 点击「下载 PNG 图片」保存高清图片

### 方法 3：部署到网络

1. 将所有文件上传到任何静态网站托管服务（如 GitHub Pages、Vercel、Netlify 等）
2. 分享链接给用户，用户可以在手机上直接访问

### 方法 4：微信分享

1. 将网站部署到网络
2. 在微信中打开链接
3. 点击右上角「...」分享给好友或朋友圈
4. 好友点击链接即可使用

## 技术实现

- **前端框架**：纯 HTML + CSS + JavaScript
- **Excel 解析**：SheetJS (xlsx)
- **图片生成**：html2canvas
- **响应式设计**：适配手机和桌面设备
- **PWA 支持**：可安装到主屏幕
- **JSBox 脚本**：iOS 端深度集成

## 注意事项

- 支持的 Excel 文件格式：.xlsx, .xls
- 生成的图片分辨率为原始表格的 3 倍，确保高清质量
- 对于大型 Excel 文件，转换时间可能会稍长
- 在手机上使用时，建议在 Wi-Fi 网络下操作
- iOS 端通过 Safari 浏览器使用体验最佳
